Пересчёт won_items + чистка loot_history

Разово пересобирает won_items у каждого персонажа с нуля из текущих рейдов → траёв → дропов, учитывая только победы в основной очереди и только по дропам, которые ещё реально существуют. Заодно удаляет записи loot_history, которые ссылаются на уже удалённые траи/дропы.

Закрывает разом обе проблемы: слоты, залоченные победой в дополнительной очереди, и слоты, которые остались залоченными после удаления трая с выигрышем. Скрипт идемпотентен — можно запускать сколько угодно раз, если снова что-то разъедется.

Доступ только для админа. После использования удалите этот файл.
